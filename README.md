# Hay Bee Concepts website

Next.js (App Router) + TypeScript, Framer Motion for scroll and filter animation, three.js for the hero particles.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Where to change things

- `lib/data.ts`: services, projects, reviews, phone and address
- `lib/whatsapp.ts`: the WhatsApp number used by every button
- `public/images/`: swap in the original photos (same file names) and the logo
- `app/globals.css`: colours are the variables at the top

Reviews in `lib/data.ts` are placeholders, replace them before launch.
